# 🎬 React & TypeScript MVVM Movie Application

A modern web application built completely through **Vibe Coding** workflows and prompt-driven engineering. This project serves as a hands-on learning playground to master clean architecture, strict TypeScript typing, and design patterns like **MVVM (Model-View-ViewModel)**.

---

## 🚀 What is this project?
Instead of just using high-level prompts, this application focuses on understanding fundamental software mechanics, separating concerns cleanly, and integrating backend services like **OMDb API** and **Firebase** into a structured React architecture.

---

## 🏛️ Architectural Highlights

- **`Models` & `Services`**: Pure business logic and external communications (fetch, Firebase integration) kept completely decoupled from React hooks and UI state.
- **`ViewModels` (Custom Hooks)**: Encapsulating state management, data-fetching lifecycles, and synchronization logic away from visual components.
- **`Views`**: Clean, modular React components focusing purely on the UI presentation layer.
- **Strict Typing**: Leveraging TypeScript interfaces to ensure type safety across data layers and prevent runtime bugs.

---

## 🛠️ Tech Stack

- **React** (with custom hooks for state orchestration)
- **TypeScript** (strict type definitions and architecture contracts)
- **React Router** (declarative routing with state-aware navigation using `NavLink`)
- **Firebase** (backend services for managing user data and favourites)
- **OMDb API** (external movie data provider)
- **Git & GitHub** (incrementally structured commit history showcasing architectural evolution)

---

## 🎯 Learning Objectives
- Transitioning from prompt-based generation to deep architectural comprehension.
- Mastering the MVVM pattern in React/TypeScript.
- Handling asynchronous data flows, custom hook reusability, and clean separation of concerns.
